# Guia de Contribuição

Este documento apresenta as orientações para contribuir com o desenvolvimento do PetAgenda.

## 1. Acesso ao repositório

O integrante deve possuir acesso ao repositório do projeto no GitHub.

## 2. Organização das branches

As alterações devem ser realizadas em branches específicas, evitando modificações diretas na branch main.

- main: versão principal do projeto.
- develop: integração das funcionalidades.
- release: preparação de versões para entrega.

## 3. Commits

As alterações devem ser registradas por meio de commits com mensagens claras, descrevendo o que foi realizado.

## 4. Pull Requests

Após concluir uma alteração, o integrante deve abrir uma Pull Request direcionada à branch develop.

A Pull Request deve apresentar um título e uma descrição que expliquem as modificações realizadas.

## 5. Revisão

As alterações devem passar por revisão antes de serem integradas à branch de destino.
