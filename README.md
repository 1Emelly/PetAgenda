
# PetAgenda 🐾

## Sobre o Projeto

O PetAgenda é um sistema web desenvolvido com o objetivo de auxiliar no gerenciamento de clínicas veterinárias, proporcionando uma melhor organização dos atendimentos e facilitando o acompanhamento dos animais.

A plataforma busca simplificar atividades do cotidiano de uma clínica veterinária, permitindo o gerenciamento de consultas, o cadastro de informações e a organização dos dados dos animais e seus tutores.

## Objetivos

- Facilitar o agendamento e o gerenciamento de consultas veterinárias.
- Organizar as informações dos animais e seus tutores.
- Auxiliar os profissionais no acompanhamento dos atendimentos.
- Melhorar a organização das atividades administrativas da clínica.
- Proporcionar uma experiência mais prática e acessível aos usuários.

## Funcionalidades

O sistema contempla funcionalidades voltadas para diferentes usuários da clínica veterinária, incluindo:

- Cadastro e gerenciamento de tutores.
- Cadastro e gerenciamento de animais.
- Organização de consultas veterinárias.
- Gerenciamento de informações dos atendimentos.
- Controle e organização das atividades da clínica.

## Público-alvo

O PetAgenda é destinado a clínicas veterinárias e seus colaboradores, incluindo veterinários, secretários, administradores e tutores de animais.

## Tecnologias Utilizadas

O projeto utiliza tecnologias voltadas ao desenvolvimento web, incluindo:

- **Frontend:** React, TypeScript e Vite.
- **Backend:** Node.js, Express e TypeScript.
- **Banco de dados:** PostgreSQL.
- **Versionamento:** Git e GitHub.

## Organização do Projeto

O desenvolvimento é organizado por meio de branches no GitHub:

- **main:** versão principal e estável do projeto.
- **develop:** integração das alterações realizadas pela equipe.
- **release:** preparação das versões para entrega.

As contribuições são realizadas por meio de branches específicas e Pull Requests, permitindo a revisão das alterações antes da integração.
